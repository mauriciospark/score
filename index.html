Auditoria de Perfil GitHub

⚠️ Token do GitHub é obrigatório para o funcionamento da ferramenta. Sem token, a análise não será realizada.

📝 Para criar um token: GitHub Settings > Personal Access Tokens

🔧 Permissões Necessárias: Ao criar seu Personal Access Token, marque apenas: repo (acesso a repositórios) e user (especificamente read:user para dados do perfil). Não selecione outras opções adicionais.

🔒 Gestão de Token: A validade e a segurança deste token são de sua responsabilidade. Monitore e revogue quando necessário no GitHub.
